# Vendored Moon skills

The Moon-related Agent Skills in this directory are vendored at immutable
upstream revisions so repository agents can use the same instructions.

The general `moon` skill is community-maintained. Treat Moon's official
documentation and schemas as authoritative if it disagrees with the installed
Moon version. `debug-task` is maintained by Moonrepo and is intended for
diagnosing an existing configured workspace.
