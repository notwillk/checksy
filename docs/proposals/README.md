# Product-family direction

Documents in this directory record the Rulesy product-family decision and
describe adjacent product work that has been designed but is not implemented
by this repository.

The Rulesy rename is implemented by the associated repository change. Rulesy's
current command names, configuration format, paths, packages, and runtime
behavior remain authoritative in the root
[README](../../README.md) and [architecture](../../ARCHITECTURE.md).

## Documents

- [Rulesy product family](rulesy-product-family.md) — records the completed
  Rulesy rename and defines the boundaries between Rulesy, RulesyOS, and Rulesy
  Compose.
- [RulesyOS product requirements and implementation design](rulesyos.md) —
  defines a firmware-style Linux substrate and the sibling `rulesy-compose`
  image-composition workflow.

RulesyOS and Rulesy Compose remain unimplemented proposals. Each requires its
own explicitly approved, independently reviewable milestone.
